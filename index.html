EPSON 투사거리 계산기 (비공식)

엡손 공식 도구 아님 / 설치 전 반드시 해당 기종 매뉴얼로 최종 확인

1. 프로젝터 및 렌즈 선택
2. 입력
3. 장비 제원
밝기 (Normal 모드, 사양서)-
해상도 / 패널 비율-
무게 (사양서)-
렌즈 방식-
적용 렌즈 / 투사비 / 시프트 -
렌즈 장착 시 밝기 (엡손 사양서) -

4. 계산 결과
    최소 투사거리 (WIDE)-
    최대 투사거리 (TELE)-
    스크린 가로-
    스크린 세로-
    스크린 대각선-
    스크린 종횡비-
    패널 전체 투사 영상 크기 (거리 계산 기준)-
    수직 시프트 (+ 위)-
    수평 시프트 (+ 오른쪽)-
    최대 화면 (WIDE)-
    최소 화면 (TELE)-
    WIDE 스크린 가로 × 세로-
    TELE 스크린 가로 × 세로-
    • 거리 = 엡손 사양서 공식 (a × 패널 영상 대각선 인치 + b). 스크린 비율이 패널과 다르면 엡손 사양서와 같은 방식(가로 또는 세로 맞춤)으로 계산합니다.
    • 시프트 mm 는 패널 영상 높이/가로폭 × % 로 계산한 값입니다. 상하·좌우를 동시에 최대로 쓸 수 없습니다.
    • 계산값은 근사치입니다. 실제 설치 전 해당 기종 매뉴얼로 확인하세요.
    5. 설치 높이
    렌즈 중심 높이 가능 범위 (바닥 기준)-
    천장 ~ 렌즈 중심 거리-
    스크린 중심 높이 (바닥 기준)-
    초단초점 b, c (사양서 그림 기준: b = 프로젝터 기준점 ~ 스크린 가까운 쪽 끝, c = 먼 쪽 끝)-
    • 렌즈 중심 기준입니다. 본체 외형·천장 브래킷 높이는 포함하지 않습니다.
    • 수평 시프트를 0 으로 둔 경우의 범위입니다. 수평 시프트를 쓰면 수직 범위가 줄어듭니다.
    • 계산 방식은 엡손 사양서의 "렌즈 중심 ~ 스크린 하단 거리" 공식과 같습니다.

    계획 위치 확인 (시프트 / 기울기 / 키스톤)

    수직-
    수평-
    • 시프트 범위를 넘는 만큼은 프로젝터를 기울여야 합니다. 기울기는 atan(넘는 거리 ÷ 투사거리)로 근사합니다.
    • 키스톤 보정 가능 범위는 엡손 사양서 표 기준입니다. 키스톤을 쓰면 영상이 작아지고 화질이 떨어집니다.
    6. 설치 그림

    측면도 (오른쪽이 스크린)

    정면도 (스크린을 바라본 모습)

    • 빨간 영역은 렌즈 중심이 위치할 수 있는 범위입니다. 상하·좌우를 동시에 최대로 쓸 수 없으므로 실제 범위는 사각형보다 좁습니다.
    • 점선은 패널 전체 영상(검은 여백 포함)입니다. 바닥 높이를 입력하지 않으면 스크린 하단을 기준으로 그립니다.
    7. 같은 조건으로 설치 가능한 기종

    현재 스크린 크기에서, 입력한 거리가 렌즈의 WIDE ~ TELE 범위 안에 드는 기종과 렌즈를 보여줍니다.

      8. 엣지 블렌딩 (여러 대 이어붙이기)
      1대당 영상 크기-
      블렌드 폭 (가로 / 세로)-
      1대당 투사거리-
      전체 영상 (검은 여백 포함)-
      • 현재 선택한 기종·렌즈와 2번에서 입력한 스크린 크기로 계산합니다. 블렌드 폭은 한 대 영상 대비 % 입니다.
      • 기종별 블렌드 폭 설정 가능 범위는 해당 매뉴얼을 확인하세요.
      9. 밝기·대비 판정

      스크린 조도 / 휘도-
      대비 (근사, 상한값)-
      판정 (ANSI/INFOCOMM 3M-2011 기준)-
      • 기준: 수동적 시청 7:1, 기본 의사결정 15:1, 분석적 의사결정 50:1, 풀모션 영상 80:1. 표준 원문은 확인하지 못했고 2차 자료 기준입니다.
      • 프로젝터의 검은색 밝기를 무시하므로 실제 대비보다 높게 나옵니다. 광원 모드·사용 시간에 따라 실제 밝기는 낮아집니다.
