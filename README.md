# Epson 투사거리 계산기 (비공식)

브라우저에서 `index.html` 을 열면 바로 동작합니다 (오프라인, 설치 불필요).
엡손(Seiko Epson)의 공식 도구가 아닙니다.

| 파일 | 역할 |

## 기능

- 스크린 크기(대각선 인치 또는 가로/세로) → 투사거리 (WIDE ~ TELE)
- 투사거리 → 가능한 스크린 크기 (역계산)
- 설치 높이: 바닥~스크린 하단 높이 입력 → 렌즈 중심 높이 가능 범위 (바닥/테이블, 천장 설치)
  - 엡손 사양서의 "렌즈 중심 ~ 스크린 하단 거리" 공식과 같은 결과 (테스트로 검증)
  - 고정 렌즈 기종은 오프셋 자료가 없어 계산하지 않음
- 설치 그림: 측면도·정면도에 렌즈 중심 가능 영역 표시
- 렌즈 장착 시 밝기: PU2220/PU2100, PQ 시리즈, PU2010/PU1000 시리즈만 (다른 기종은 사양서에 표 없음)
- 같은 조건으로 설치 가능한 기종: 현재 스크린 크기 + 설치할 투사거리 → 가능한 본체·렌즈 조합
- 길이 단위 선택 (m / mm / ft)
- 결과 복사 (메신저·메모에 붙여넣기)

## 계산 기준

- 거리(cm) = a × 패널 영상 대각선(인치) + b
  - a, b 는 엡손 사양서의 렌즈별 "Projection Distance Formula" 값입니다.
- 설치 높이: 영상 중심 = 렌즈 중심 + 수직 시프트(%) × 패널 영상 높이 (천장 설치는 상하 반전)
- 스크린 비율이 패널과 다를 때(엡손 사양서와 같은 방식)
  - 스크린이 더 넓으면 가로 맞춤 (패널 가로 = 스크린 가로)
  - 스크린이 더 좁으면 세로 맞춤 (패널 세로 = 스크린 세로)
